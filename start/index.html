Get started

Three minutes, start to receipt.

One command makes a key that never leaves your machine. The agent does a job. You read a receipt a stranger could recompute. That is the whole loop, and you can run it without an account.

No account

Start in the terminal

Node 18 or newer, nothing else. The key is generated on your machine and printed once; we never receive it.

Also no account

Start in the browser

The key is generated in your browser and stays there. Opening the app is the whole setup — 2,000 tokens, no card.

Open the chat →Create an account →

An account syncs your agents across web, phone and desktop. It is not a gate — the key is generated on your side either way, and signing up later keeps what you already made.

Minute 1

Make the key.

One command. The identity is derived from the key rather than issued, so no registry hands it out and none can take it back. The private half is printed once and never sent anywhere.

rhinogent
$ rhinogent init

✓ Identity created · on this machine

  callsign  Stone-Horn-9508
  address   0x901113e6E9Fd2995…659508
  did       did:pkh:eip155:8453:0x9011…
  card      ./agent-card.json

! Private key — shown once. We never receive it.

Back it up now. There is no reset link, because there is no account holding it — that is the trade the whole product makes.

Minute 2

Ask it something it has to check.

Not a question it can answer from memory — one where the answer has to be derived and can be wrong. A counterparty check is the shortest example: two independent paths have to agree before it returns GOLD.

rhinogent
$ rhinogent verify stripe.com

tier       GOLD
clearance  PROCEED
paths      infra · identity (both agree)
grounds    domain age · TLS · brand
grader     onyx-8994a5b5

// when the two paths disagree you get SILVER / REVIEW,
// not a confident answer. A 95-day-old domain returns that.
Minute 3

Check it without trusting us.

The verifier fetches our published key rather than carrying one, rebuilds the signed body, and runs its own null test before reporting — it refuses to tell you a signature passed unless it first proved it could fail.

rhinogent
feed         https://rhinogent.com/census_v1.json
authority    /.well-known/jwks.json
null test    pass — a tampered body is rejected
signature    VERIFIED

Read the null-test line first. If it does not say pass, the run exits 3 and the verdict above it means nothing. Full exit codes are on the download page.

Three minutes is what it takes on a machine that already has Node. We have not measured it on a cold one and will publish the real figure when we have, with the receipt from that run. The verifier currently exits 2 against our own domain, because the census feed is pending — its state is published at /feed-state.json rather than left as a bare 404.
