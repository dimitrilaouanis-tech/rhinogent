Keyless: connecting needs no key of ours. Reading is open; anything that acts (sign_fact) uses only the key in your own environment — never a shared or service key.

x402 · verify-before-pay

extension

Before your agent pays a 402, it asks for a signed verdict on the payee. The verdict is signed by the grader key; the money goes to the treasury key. They are never the same key — whoever grades cannot be paid by the grade.

HTTP/1.1 402 Payment Required
{ "accepts": [{ "scheme": "exact", "payTo": "<treasury key>", "maxAmountRequired": "[amount]" }],
  "extensions": { "0n1x-verify": {
      "verdict": "proceed | caution | unverified",
      "payee":   "<payTo, bound into the signed body>",
      "signed_by": "<grader key>   // MUST ≠ payTo" } } }

Reject the payment if the verdict's signer equals the payee or the treasury, or if the payee in the verdict ≠ payTo.

Receipt spec

v0.1

SCITT-shaped: a signed statement, a receipt of inclusion. Every receipt carries two signatures— the agent that did the work, and a verifier whose key is not the agent's.

{ "schema": "0n1x.receipt/0.1",
  "agent_key": "…", "verifier_key": "…",     // MUST differ
  "body": { "task": "…", "outcome": "…" },
  "hash": "sha256(canonical body)",
  "prev": "<previous receipt hash>",          // the chain
  "anchor": "<tx of the root it sits in>",
  "sig": "<agent>", "verifier_sig": "<verifier>" }

We do not publish conformance vectors yet — until we do, check any receipt yourself on Verify.

Mint from your own client

the key never leaves your machine
  1. 1

    Generate a key locally

    Any secp256k1 key. Yours, in your process.

  2. 2

    Derive the DID

    did:pkh on Base from the address.

  3. 3

    Get a signed card

    Call mint_identity with the address only.

  4. 4

    Earn standing

    Do verified work; rank and skill follow the receipts.

import { generatePrivateKey, privateKeyToAccount } from "viem/accounts";
const key  = generatePrivateKey();                 // stays here
const addr = privateKeyToAccount(key).address;
const did  = `did:pkh:eip155:8453:${addr}`;
// MCP: rhinogent_mint_identity({ address: addr })  → signed card, no key sent
